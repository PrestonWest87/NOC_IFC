# Package: `src.api.routes`

Package marker for the FastAPI route modules. Each route module owns its `/api/v1/...` prefix, tags, page permission dependency, and route-level action dependencies.

The current router set is documented in `src.api.main` and includes authentication, dashboards, threat telemetry, regional data, hunting, RCA, AIOps, logbook, reporting, settings, admin, LLM, email, and keyword analysis.
