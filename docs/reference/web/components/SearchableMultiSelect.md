# Component: `SearchableMultiSelect`

**Source:** `web/src/components/SearchableMultiSelect.tsx`

The controlled multi-select presents selected values as removable chips and available values as a searchable checkbox list, avoiding native scroll-and-highlight selection. It is used for associated circuit IDs in Settings and circuit selection in Operational Email. Search filters existing options; it does not create new references. Operational Email's editable Network Orders/Circuit IDs field and configured-ID paste handling remain available alongside the picker.
